官方 OpenWrt 25.12.6 bcm27xx/bcm2710 SDK 构建的第三方 APK。

支持范围：树莓派 3B+、GPIO18（物理引脚 12）、硬件 PWM0、1 kHz。
必须先启用正确的 PWM 设备树 overlay；安装包不会修改启动分区。

包含手动调速、自动温控/滞回、开关、阈值配置、状态显示、开机自启和退出全速保护。
控制器核心已在树莓派 3B+ 实机验证 0/50/100% PWM、网页保存、掉电重启自启。
新的 APK 构建/安装验证范围见仓库测试记录。

**这是第三方未配置可信分发签名的 APK，不属于 OpenWrt 官方软件源。**
安装前核对 SHA256；安装命令、升级和卸载见附件 INSTALL.md。
不支持网页直接更换 GPIO，也不提供风扇实际 RPM 测量。
